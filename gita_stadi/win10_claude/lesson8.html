8강 · 이 공부방은 이렇게 만들었어요

클로드(AI)가 하루 만에 공부방·숏츠·블로그를 만들고 세 곳에 올린 과정이에요. 무엇을 어디에 올렸는지 순서대로 봐요.

▲ 함께 만든 1분 쇼츠 (목소리 + 3D 화면)

① 공부방(이 사이트) 만들기

  1. 클로드가 build.cjs라는 ‘설계도’ 파일 하나에 8쪽 내용을 적어요.
  2. 설계도를 실행하면 html 파일 8개 + style.css가 자동으로 만들어져요.
  3. SVG 움직이는 그림: 글자로 그린 그림이라 폰에서도 선명하고 가벼워요.
  4. 3D 입체 그림: three.js라는 무료 3D 도구로 건물을 만들어요.
  5. GIF: 화면을 여러 장 찍어 ffmpeg 프로그램으로 이어 붙여요.

③ 1분 숏츠 만들기

  1. 대본 7줄을 써요. (카페24가 뭐예요? → … → 설명란 링크!)
  2. AI 목소리(마이크로소프트 선희 음성)로 7줄을 읽게 해요.
  3. 목소리 길이에 맞춰 3D 화면을 1초에 24장씩, 약 1,560장 찍어요.
  4. ffmpeg로 그림 + 목소리를 합쳐 세로 영상(1080×1920)을 만들어요.
  5. 유튜브 스튜디오에서 업로드 → 제목·설명 → 공개.

④ 네이버 블로그 쓰기

  1. 블로그 글쓰기 화면을 열어 제목 → 본문을 차례로 넣어요.
  2. 움직이는 그림(GIF) 4개와 숏츠 사진을 넣어요.
  3. 카테고리 AI·컴퓨터 활용, 태그 8개를 넣고 발행.
