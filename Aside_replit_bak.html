Aside 제작 왕초보 레슨

Replit 앱 → GitHub 이동 · 백업 · 발행 교실

성실피아노 / park(Replit) / poianopks.github.io · Aside가 Replit을 직접 탐색하고 Claude 레슨과 합쳐 만든 페이지입니다.
짝 페이지(Claude 원본 계열): claude_replit_bak.html

왜 필요한가? Replit 공개 주소(*.replit.app)는 앱을 끄면 안 열릴 수 있습니다. GitHub Pages(poianopks.github.io)는 파일이 남아 있으면 주소가 안정적입니다. 애드센스도 GitHub 도메인이 유리했습니다.

2. 왕초보: GitHub로 옮기는 방법 (5단계)

  1. 1) Replit에서 만들거나 열어 둔 앱의 .html / 코드를 복사하거나 다운로드합니다.
  2. 2) 브라우저에서 poianopks.github.io 저장소를 엽니다.
  3. 3) Add file → Upload files (또는 새 파일 만들기).
  4. 4) 파일 이름 예: my-app.html → Commit changes.
  5. 5) 1~2분 뒤 주소: https://poianopks.github.io/my-app.html

Aside는 GitHub에 직접 올릴 수 있습니다. Claude는 GitHub App 쓰기 권한이 없으면 403으로 발행이 막힐 수 있습니다(이번 Claude 작업이 그 경우).

3. 백업이란?

  • Replit만 있으면 → 계정·요금·중지 시 위험
  • GitHub에 같은 HTML을 두면 → 복사본(백업) + 공개 사이트
  • PC 폴더 Claude / Aside\\Claude에도 파일을 두면 3중 안전
