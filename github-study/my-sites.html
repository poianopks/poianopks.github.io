1. 딱 3단어만 알면 돼요

🏷️
도메인= 주소

flowers1.co.kr 처럼 사람이 외우는 인터넷 주소예요. 해마다(또는 몇 년마다) 돈을 내고 연장해요.

🏠
서버 · 호스팅= 집

홈페이지 파일이 실제로 사는 곳이에요. 저는 Cloudflare Pages 와 GitHub Pages 를 써요.

🪧
네임서버= 안내판

"이 주소의 집은 저기예요" 하고 길을 알려 주는 표지판이에요.

📦 하나 더: GitHub 저장소 = 창고. 홈페이지 파일을 보관하는 곳이에요. 창고에 새 파일을 넣으면(푸시) 집(서버)이 알아서 새것으로 바뀌어요.
