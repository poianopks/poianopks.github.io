파이썬이 무엇인가요?

파이썬은 컴퓨터에게 무엇을 어떻게 하라고 글로 명령하는 언어입니다.

print("안녕하세요")

컴퓨터에게 “안녕하세요를 화면에 보여줘”라고 부탁한 것입니다.

DAY 01

print() — 화면에 보여주기

개념: print()는 글자, 숫자, 계산 결과를 화면에 보여주는 명령어입니다.
print("안녕하세요")
print(10)
print(7 * 8)
실행 결과안녕하세요 10 56

글자는 따옴표 안에 넣고, 숫자와 계산은 따옴표 밖에 씁니다. 글자와 계산을 함께 보여줄 때는 쉼표로 나눕니다.

print("7 곱하기 8은", 7 * 8, "입니다")
실행 결과7 곱하기 8은 56 입니다
오늘의 기억: print() = “화면에 보여줘!”
DAY 02

변수 — 이름표가 붙은 상자

개념: 변수는 글자나 숫자를 보관하는 이름표 상자입니다.
이름 = "박근성"
나이 = 67

print(이름)
print(나이)
실행 결과박근성 67

=는 “오른쪽 값을 왼쪽 상자에 넣어라”라는 뜻입니다. 변수 이름은 한글로 지을 수도 있습니다.

print(이름)    # 상자 안의 내용: 박근성
print("이름")  # 글자를 그대로: 이름
오늘의 기억: 변수 = 값을 보관하는 이름표 상자
DAY 03

숫자와 문자 — 내용물의 종류

개념: 파이썬에서는 자료의 종류를 타입(type) 또는 자료형이라고 합니다.
종류예뜻
정수67소수점 없는 숫자
실수170.5소수점 있는 숫자
문자열"67"따옴표 안의 글자
print(10 + 20)      # 숫자 계산
print("10" + "20")  # 글자 이어 붙이기
실행 결과30 1020
오늘의 기억: 67은 숫자, "67"은 글자입니다.
DAY 04

계산 — 더하기·빼기·곱하기·나누기

계산기호예결과
더하기+10 + 212
빼기-10 - 28
곱하기*10 * 220
일반 나누기/10 / 25.0
몫만 구하기//10 // 33
나머지%10 % 31
가격 = 5000
개수 = 3
합계 = 가격 * 개수

print("합계는", 합계, "원입니다")
실행 결과합계는 15000 원입니다
오늘의 기억: 일반 나누기는 / 하나, 몫만 구할 때는 // 두 개를 붙여 씁니다.
DAY 05

input() — 사람에게 물어보기

개념: input()은 사용자에게 질문하고 입력한 대답을 받습니다.
이름 = input("이름을 입력하세요: ")
print("안녕하세요", 이름, "님")
박근성을 입력했을 때안녕하세요 박근성 님

input()으로 받은 내용은 기본적으로 글자입니다. 계산하려면 int()로 정수로 바꿉니다.

나이 = int(input("나이를 입력하세요: "))
print("내년에는", 나이 + 1, "세입니다")
67을 입력했을 때내년에는 68 세입니다
오늘의 기억: input() = “물어보고 대답을 받아줘!”
DAY 06

if — 만약에

개념: 조건이 맞을 때와 맞지 않을 때, 컴퓨터가 서로 다른 일을 하도록 만드는 갈림길입니다.
나이 = 67

if 나이 >= 65:
    print("경로 우대 대상입니다")
else:
    print("아직 대상이 아닙니다")
실행 결과경로 우대 대상입니다
기호뜻
>크다
<작다
>=크거나 같다(이상)
<=작거나 같다(이하)
==서로 같다
!=서로 다르다

=는 값을 상자에 넣기, ==는 두 값이 같은지 비교하기입니다.

오늘의 기억: if = “만약 조건이 맞으면 이 일을 해줘!”
DAY 07

len() — 개수 세기

개념: len()은 글자의 길이나 리스트 안의 개수를 셉니다.
이름 = "박근성"
문장 = "피아노 조율"

print(len(이름))
print(len(문장))
실행 결과3 6

피 + 아 + 노 + 띄어쓰기 + 조 + 율 = 6입니다. 띄어쓰기도 한 글자로 셉니다.

오늘의 기억: len() = “몇 개인지 세어줘!”
DAY 08

리스트 — 여러 칸이 있는 큰 상자

개념: 리스트는 여러 값을 순서대로 한꺼번에 보관합니다. 대괄호 [ ]를 사용합니다.
악기들 = ["피아노", "바이올린", "기타"]

print(악기들)
print(악기들[0])
print(악기들[1])
실행 결과['피아노', '바이올린', '기타'] 피아노 바이올린

파이썬은 첫 번째를 1번이 아니라 0번부터 셉니다.

오늘의 기억: 리스트 = 여러 값을 순서대로 담는 큰 상자
DAY 09

for — 똑같은 일 반복하기

개념: for는 리스트의 값을 하나씩 꺼내며 같은 일을 반복합니다.
악기들 = ["피아노", "바이올린", "기타"]

for 악기 in 악기들:
    print(악기, "연주를 해봅시다")
실행 결과피아노 연주를 해봅시다 바이올린 연주를 해봅시다 기타 연주를 해봅시다

for 아래에서 반복할 명령 앞에는 반드시 들여쓰기를 합니다.

오늘의 기억: for = “하나씩 꺼내서 반복해!”
DAY 10

개념: 함수는 여러 명령을 하나로 묶어서 필요할 때 부르는 나만의 명령어입니다.
def 인사하기(이름):

인사하기("박근성")

오늘의 기억: def = “새로운 명령어를 만들겠습니다!”

CHAPTER 0 · 연결

배운 기초가 실용 도구로 변합니다

서사: 어제까지 변수는 단순한 ‘이름표 상자’였습니다. 오늘부터 그 상자에는 주가, 피아노 음, 고객 이름, 뉴스 제목이 들어갑니다. 문법은 그대로인데 쓸모가 커집니다.

변수 → 기억

현재주가 = 80000
필요한 값을 이름 붙여 보관합니다.

if → 판단

수익이면 “상승”, 손실이면 “하락”처럼 조건에 따라 판단합니다.

리스트 → 자료 묶음

여러 날짜의 주가나 여러 음을 한 상자에 담습니다.

for → 반복 작업

주가 100개, 음표 100개를 하나씩 자동 처리합니다.

핵심: 파이썬의 힘은 어려운 문법보다 기억 → 계산 → 판단 → 반복을 빠르고 정확하게 시키는 데 있습니다.

CHAPTER 1 · 실용생활

할인 가격 계산기

가격표를 보고 머리로 계산하던 일을 변수와 계산 기호로 처리합니다.

PYTHON
원래가격 = 120000

할인금액 = 원래가격 * 할인율 / 100

무슨 일이 일어났나요? 12만 원의 20%인 2만 4천 원을 구하고, 원래 가격에서 뺐습니다.

CHAPTER 2 · 실용경제

물가가 오르면 내 돈의 힘은?

은행에 돈이 그대로 있어도 물가가 더 빠르게 오르면 살 수 있는 물건의 양은 줄어듭니다. 파이썬은 이 관계를 숫자로 보여줍니다.
PYTHON
예금이자율 = 3.0
물가상승률 = 4.0
실질이자율 = 예금이자율 - 물가상승률

if 실질이자율 > 0:
    print("돈의 구매력이 늘었습니다")
else:
    print("돈의 구매력이 줄었습니다")

print("단순 실질이자율:", 실질이자율, "%")
돈의 구매력이 줄었습니다 단순 실질이자율: -1.0 %
왕초보 주의: 위 계산은 개념을 배우기 위한 단순 계산입니다. 실제 세금, 복리, 정확한 실질수익률 공식은 더 고려해야 합니다.

CHAPTER 3 · 실용주식

수익률 계산과 아주 단순한 판정

매수가와 현재가를 변수에 담으면 수익률을 자동으로 계산할 수 있습니다.

PYTHON
매수가 = 70000
현재가 = 77000
수익률 = (현재가 - 매수가) / 매수가 * 100

print("수익률:", round(수익률, 2), "%")

if 수익률 > 0:
    print("현재 수익 구간입니다")
elif 수익률 == 0:
    print("본전입니다")
else:
    print("현재 손실 구간입니다")
수익률: 10.0 % 현재 수익 구간입니다

내 숫자로 수익률 맛보기

버튼을 누르면 답이 나옵니다.
중요: 수익률이 양수라는 사실만으로 매수·보유 판단을 할 수는 없습니다. 실적, 현금흐름, 부채, 산업, 가격 수준과 위험을 함께 봐야 합니다.

여러 날의 평균 주가

PYTHON
주가들 = [70000, 71000, 69000, 73000, 77000]
평균주가 = sum(주가들) / len(주가들)

print("5일 평균:", 평균주가)
5일 평균: 72000.0
연결: 리스트가 여러 주가를 담고, sum()이 합계를, len()이 개수를 구합니다.

CHAPTER 5 · 실용음악

코드도 리스트가 됩니다

피아노에서 C코드는 도·미·솔입니다. 파이썬에서는 이 세 음을 리스트에 담을 수 있습니다. 음악이 ‘느낌’인 동시에 ‘자료’가 되는 순간입니다.
PYTHON
C코드 = ["도", "미", "솔"]
Am코드 = ["라", "도", "미"]

for 음 in C코드:
    print(음)

print("C코드의 음 개수:", len(C코드))
도 미 솔 C코드의 음 개수: 3

코드 사전 만들기

PYTHON
코드사전 = {
    "C": ["도", "미", "솔"],
    "Am": ["라", "도", "미"],
    "G7": ["솔", "시", "레", "파"]
}

print("G7의 구성음:", 코드사전["G7"])
G7의 구성음: ['솔', '시', '레', '파']
새 문법 맛보기: 중괄호 { }로 만든 딕셔너리는 이름과 값을 짝지어 보관합니다. 실제 사전에서 단어를 찾는 것과 비슷합니다.

CHAPTER 7 · MIDI

MIDI는 소리보다 ‘연주 명령’에 가깝습니다

MIDI 정보뜻피아노에 비유
note어떤 높이의 음인가어느 건반인가
velocity얼마나 강하게 눌렀나셈여림
duration얼마나 오래 유지하나음의 길이
MIDI 개념 맛보기
음표 = {
    "note": 60,
    "velocity": 80,
    "duration": 1.0
}

print("MIDI 음번호:", 음표["note"])
print("연주 세기:", 음표["velocity"])
MIDI 음번호: 60 연주 세기: 80
핵심: MIDI 60은 보통 가운데 도(C4)를 뜻합니다. 실제 소리는 사용하는 피아노·신시사이저 음원에 따라 달라집니다.
