AI 자동화

원고·이미지·판매페이지·SNS 홍보·댓글 응대까지 전부 AI 처리. 유튜버는 지시만.

📣

기존 팬덤

유튜브 구독자+오픈채팅방+쓰레드 팔로워. '팔아줄 손님'이 이미 모여있었음.

⚡

즉각 실행

아이디어 → 72시간 안에 상품화·판매 완료. 생각만 하지 않고 AI에게 즉시 시킴.

💡 핵심 공식: 좋은 도구(AI) × 팔아줄 사람(팬덤) × 즉각 실행 = 매출. 이 셋 중 하나라도 빠지면 결과가 크게 달라집니다.

그러나 과정 자체는 누구나 배울 수 있습니다. AI로 전자책 쓰기, 이미지 만들기, 판매 페이지 올리기는 오늘 당장 따라할 수 있어요. 단, 팔릴 채널(블로그·SNS·커뮤니티)을 먼저 키우는 것이 선행 조건입니다.

📖 기본·전문 용어 풀이 사전 ▼

바이브 코딩 (Vibe Coding)

코드 문법 몰라도 AI에게 느낌으로 '이렇게 만들어줘' 말로 시켜서 프로그램 완성하는 방식

CLI (Command Line Interface)

마우스 클릭 대신 검은 창에 글자를 입력해서 컴퓨터를 조종하는 방식. Claude Code가 이 방식으로 동작

에이전트 (AI Agent)

단순 질문 답변이 아니라 목표를 세우고 컴퓨터를 직접 조작하며 일 처리하는 AI. Claude Code가 파일 만들고 브라우저 제어한 것이 에이전트 동작

Fable 모드

Claude Code의 강력한 자율 실행 모드. 승인 없이 스스로 판단해 최선의 작업을 수행. 2025년 당시 화제였음

Orca (오르카)

오픈소스 에이전트 IDE. 모바일에서도 Claude Code를 원격 조종 가능. 윤자동이 핸드폰으로 AI 감독할 때 사용

YB CLI

윤자동(윤 비서)이 직접 만든 커스텀 CLI. 모든 프로젝트 데이터를 AI에게 한 번에 전달하는 도구

Threads (쓰레드)

메타(인스타그램 회사)의 텍스트 SNS. AI가 API + 브라우저 제어로 홍보 글 자동 게시·댓글 응대

래피드 (Laffy)

전자책·PDF 디지털 파일 판매 플랫폼. AI가 직접 로그인 후 상품 등록·이미지 업로드 수행

CTA (Call To Action)

'지금 구매하기', '천원으로 시작하기'처럼 고객이 버튼을 누르도록 유도하는 마케팅 장치

Puppeteer (퍼피티어)

코드로 크롬 브라우저를 자동 조종하는 도구. Claude Code가 이걸 써서 주황색 마우스로 브라우저를 직접 클릭·입력

포함할 것:
1. 눈길 끄는 제목 3개 (궁금증 유발형)

3. "이런 사람에게 추천" 리스트
4. 목차 소개 (가치 강조)
5. 마무리 CTA 버튼 문구 (예: "지금 X원에 시작하기")
