📌 1부. 영상의 핵심 골격 & 엑기스 요약

영상의 핵심은 한 마디로 "코딩 한 줄 안 쓰고, 자연어 설명만으로 모바일 앱(iOS 앱스토어용)까지 만들어 배포한다"는 것입니다.

1. 외주·강의 없이 즉시 제작예전엔 앱 하나 만들려면 외주비 수백만 원 + 몇 달 강의 수강이 필요했지만, 이제는 "내가 원하는 대로" 설명만 하면 됨
2. 프론트엔드 + 백엔드 + 호스팅 통합Replit이 서버, 데이터베이스, 배포까지 한 곳에서 다 처리
3. Describe(설명창)에 한국어로 입력"오늘 점심 뭐먹지 앱 만들어줘, 메뉴 추천 + 네이버 지도 연결 + 레시피 표시" 처럼 자연어로 기획
4. API 키 자체 제공보통 OpenAI 등 AI API 키를 따로 발급·결제해야 하는데, Replit이 자체 키를 대신 사용 → 초보자 진입장벽 ↓
5. QR 스캔으로 모바일 즉시 테스트Expo Go 앱을 폰에 깔고 QR만 찍으면 → 내가 만든 앱이 바로 폰에서 실행됨
6. Publish to App Store 버튼클릭 한 번으로 Apple App Store 빌드(약 45분 소요) → 알림으로 완료 통지
7. Apple Developer 가입 필요앱스토어 등록은 연 $99(약 13~14만 원) 유료 (Replit 외 별도 비용)
8. 비개발자 시대의 도래"아이디어만 있으면 혼자서도 서비스를 만드는 시대"라는 메시지

📌 2부. Replit이란?

기본 개념

  • 설립: 2016년, 미국 샌프란시스코 본사
  • 정체성: 브라우저에서 바로 코딩·실행·배포가 되는 클라우드 통합 개발 환경(IDE)
  • 지원 언어: Python, JavaScript, HTML/CSS, Java, C++, Go, Rust 등 50개 이상
  • 설치 불필요: 웹 브라우저만 있으면 됨 (안드로이드폰에서도 OK)

핵심 무기 — Replit Agent

  • 2024년 출시된 AI 자동 코딩 도우미
  • 자연어 프롬프트만 입력하면 → 파일 구조 설계 → 코드 작성 → 패키지 설치 → 데이터베이스 세팅 → 배포까지 자동

주요 기능

  • Workspaces: 프로젝트 단위 작업 공간
  • Create something / Import code: 새로 만들기 또는 GitHub에서 가져오기
  • Projects / Published Projects: 작업 중 / 배포 완료된 프로젝트
  • Integrations: OpenAI, Stripe, Database 등 외부 연동
  • Deployments: 자동 호스팅 (.replit.app 도메인 자동 부여)
  • Mobile App Publishing: "Publish to App Store" 신기능
  • Secrets: API 키 등 비밀 환경변수 안전 보관

요금제 (2026년 기준)

  • Starter (무료): 기본 사용, 일정 시간 후 슬립
  • Replit Core (유료, 약 $20~25/월): Agent 크레딧, 항상 실행, 더 많은 리소스
  • Teams: 협업용

특히 유용한 활용처

  • 🎹 피아노 조율 예약 사이트
  • 🛒 네이버 스마트스토어 보조 도구: 재고 관리, 주문 알림
  • 📈 주식 분석 자동화: 종목 스크리닝, 차트 분석
  • 🎵 음원 발매 랜딩 페이지

📌 3부. 1번부터 끝까지 따라하기

진행률 0/8 (체크 상태는 이 브라우저에 저장됩니다)

화면 상단의 + Create something... 버튼을 탭하면 "What do you want to make?" 입력창이 뜹니다. 한국어로 자연스럽게 입력하세요 (예시):

피아노 조율 예약 받는 웹사이트를 만들어줘.
고객 이름, 전화번호, 주소, 희망 날짜와 시간을 입력받고,
피아노 종류(업라이트/그랜드)를 선택하게 해줘.
예약 목록은 관리자 페이지에서 볼 수 있어야 해.

Start building 버튼 클릭.

Replit Agent가 자동으로:

  • 프로젝트 폴더 생성
  • 패키지 설치 (Flask, SQLite 등)
  • HTML/CSS 디자인 작성
  • 백엔드 API 코드 작성
  • 데이터베이스 테이블 자동 생성

진행 상황이 채팅창에 한 줄씩 표시되며 약 2~5분 소요됩니다 (영상에서는 메뉴 추천 앱이 빌드됨).

빌드가 끝나면 오른쪽에 Webview(미리보기 창)가 나타납니다. 직접 폼을 채워보며 잘 작동하는지 테스트하고, 수정하고 싶으면 채팅창에 추가 요청합니다:

예약 완료 후 "감사합니다" 메시지를 띄우고
카카오톡 채널로 연결되는 버튼을 추가해줘
  • 모바일 앱이라면 화면 오른쪽 QR 코드 영역 찾기
  • 폰에 Expo Go 앱 설치 (구글 플레이 / 앱스토어) — 영상에서 "X4Go"로 들리지만 실제로는 Expo Go(엑스포 고)
  • Expo Go 앱 실행 → Scan QR 클릭
  • Replit 화면의 QR을 찍으면 → 폰에서 내 앱이 실행됨!
  • 우상단 Publish 또는 Deploy 버튼 클릭
  • "Made with Replit" 배지 넣을지 묻는 창에서 선택
  • 빌드 → 번들링 → 배포 진행 (수 분 소요)
  • https://내앱이름.replit.app 주소 자동 발급
  • 이 주소를 카톡, 블로그에 공유하면 누구나 접속 가능

이 단계는 Apple Developer Program 연 $99 결제가 필요합니다.

  1. https://developer.apple.com 가입 → 연회비 결제
  2. Replit에서 Publish to App Store 클릭
  3. Apple ID 연결 (영상에서 강조한 부분)
  4. 빌드 시작 → 약 45분 후 알림 도착
  5. App Store Connect에서 앱 아이콘, 스크린샷, 설명 작성
  6. 심사 제출 (통과 여부는 앱 품질·정책 준수에 따라 다름)
Agent가 영어로만 답함채팅창에 "한국어로 답해줘" 입력
무료 크레딧 소진Replit Core 구독 (월 $20~25)
한글 깨짐"UTF-8 인코딩으로 설정해줘" 요청
API 키 노출 걱정Secrets 탭에 보관 (코드에 직접 X)
앱이 느려짐무료 플랜은 슬립 → 유료 플랜으로 항상 실행

피아노 조율 35년 경력 + 스마트스토어 + 주식 분석을 하시는 만큼:

  • 미션 1: 피아노 조율 견적 자동 계산기 웹앱 — 지역 + 피아노 종류 + 조율 빈도 입력 → 견적 자동 산출
  • 미션 2: 관심 종목 모니터링 대시보드 — Python + yfinance로 실시간 시세 → 매수/매도 알림
  • 미션 3: 내 작곡 포트폴리오 사이트 — 음원 업로드 + 스트리밍 + 구매 링크

각 미션을 STEP 1의 자연어 입력란에 그대로 붙여넣으면 Replit Agent가 만들어 줍니다.
