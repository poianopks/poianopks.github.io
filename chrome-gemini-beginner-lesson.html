PC 크롬 레이아웃

모바일·세로 감각

1. 크롬 + 제미니가 뭔가요?

구글 크롬인터넷 보는 프로그램(브라우저). 주소 입력, 탭, 북마크, 확장 프로그램.
Gemini (제미니)구글 AI. 크롬에 고정 버튼으로 붙어, 지금 보는 페이지를 보면서 질문 가능.
Aside와 닮은 점: 왼쪽(또는 가운데)=사이트 화면 · 오른쪽(또는 옆 패널)=AI 대화. 크롬의 「Gemini에게 물어보기」가 그 역할입니다.

2. 상단 제목·타이틀 용어 (쉬운 풀이)

보이는 이름쉬운 뜻언제 쓰나
탭 / 탭 제목지금 연 페이지 이름 칸여러 사이트 동시 열 때
주소창 (옴니박스)주소 치거나 검색하는 긴 칸사이트 이동·검색
뒤로 / 앞으로 / 새로고침이전·다음·다시 불러오기페이지 이동 실수 복구
별(북마크)즐겨찾기 저장자주 가는 레슨 URL 저장
Gemini에게 물어보기구글 AI 바로 열기이 페이지 요약·질문
확장 프로그램 아이콘크롬에 붙인 작은 도구번역, 광고차단 등
프로필 사진구글 계정로그인·동기화
창 최소화 / 최대화 / 닫기창 크기·종료작업표시줄 정리
스크린샷 기준: 주소창 오른쪽 끝 근처에 별, 확장, 그리고 둥근 Gemini에게 물어보기 버튼이 보입니다.

3. 우측(또는 옆) 제미니 패널 용어

용어쉬운 뜻
Gemini 사이드 패널페이지 옆에 붙는 AI 대화창
이 탭/페이지 기준 질문지금 보고 있는 글 내용을 바탕으로 물어봄
프롬프트 / 질문 입력란할 말을 적는 칸
요약해 줘긴 글을 짧게
쉽게 설명해 줘왕초보 말로 다시
할 일 목록으로단계를 체크리스트로
닫기 / 축소패널 치우기 (페이지만 크게)

구글 검색 화면 안 용어

  • Gmail — 구글 메일
  • 이미지 — 그림 검색
  • 앱 격자(점 9개) — 드라이브·유튜브 등 구글 앱 모음
  • AI 모드 — 검색창 근처 AI 검색 전환

4. 왕초보 써보기 (3분)

  1. 크롬을 켠다 → google.com 또는 레슨 사이트 연다.
  2. 상단 Gemini에게 물어보기를 누른다.
  3. 예: 「이 페이지를 왕초보에게 5줄로 요약해 줘」
  4. 예: 「상단 메뉴 용어를 표로 정리해 줘」
  5. 답 보고 → 또 물어보기 → 필요하면 복사해 메모.
유용한 점: 페이지를 오가며 설명·번역·요약·체크리스트를 같은 창에서 끝낼 수 있음. 탭을 수십 개 열 필요가 줄어듦.

5. 확장 프로그램이란? (크롬 + AI 연관)

확장 프로그램 = 크롬에 붙이는 작은 추가 기능. 주소창 오른쪽 퍼즐/아이콘 자리에 나타납니다.

종류 예하는 일주의
번역외국어 페이지 한글로신뢰 가능한 출처만
광고 차단광고 줄이기사이트 수익 페이지는 예외 가능
비밀번호 관리로그인 도움공식 스토어 권장
AI 도우미 확장요약·작성 보조Gemini 내장과 역할이 겹칠 수 있음
관계: Gemini는 구글이 크롬에 넣어 둔 AI 통로. 확장은 제3자 도구. 둘 다 “브라우저 위 도우미”지만 설치·권한·로그인 방식이 다릅니다.
  1. 크롬 웹 스토어에서 검색
  2. 「Chrome에 추가」
  3. 권한 확인 후 사용
  4. 불필요하면 제거 (chrome://extensions)

6. Aside AI 레슨 화면 vs 크롬+제미니

둘 다 “화면 보면서 AI”입니다. 공부·요약은 Gemini, 사이트 만들기·배포·발행 대행은 Aside가 강합니다.
