내 Replit 앱, 안전하게 백업하고 옮기는 법

Replit은 쓸수록 요금이 나와요. 앱을 지우거나 요금제를 바꾸기 전에, 내 코드를 내 컴퓨터와 GitHub에 남겨두는 방법을 배웁니다. 오늘은 배우기만 하고, 실제 이동은 준비가 되면 하세요.

먼저 두 가지 차이부터

방법 A

백업 = ZIP 다운로드

앱 전체를 압축 파일 하나로 내 PC에 복사해 두는 것. 사진을 USB에 옮겨 두는 것과 같아요. 가장 쉽고 무료.

방법 B

이동 = GitHub 연결

코드를 GitHub 저장소에 올려 인터넷에 보관하는 것. 피아노 조율 기록을 장부에 날짜별로 남기듯, 바뀐 내역이 다 기록돼요.

방법 A · 5분

ZIP으로 백업하기

  1. replit.com에 로그인하고 백업할 앱을 엽니다.
  2. 왼쪽 파일 목록(Files) 맨 위에 있는 ⋮ 점 3개 메뉴를 누릅니다.
  3. Download as zip을 누르면 압축 파일이 다운로드 폴더에 저장됩니다.
  4. 파일 이름을 앱이름_2026-10-03.zip처럼 날짜를 붙여 바꾸고, 문서\Replit백업 폴더에 모아 둡니다.
  5. 다운로드가 실패하면(앱이 너무 큼) 아래 Shell 창에 zip -r project.zip . -x "node_modules/*" ".cache/*"를 붙여넣고 실행한 뒤, 생긴 project.zip을 파일 목록에서 내려받습니다.
방법 B · 15분

GitHub로 옮기기

  1. Replit 계정 설정의 연결된 서비스(Connected services)에서 GitHub 계정을 연결합니다. 한 번만 하면 돼요.
  2. 앱을 열고 도구 목록에서 Git 도구를 엽니다.
  3. 새 저장소를 만들거나 기존 저장소를 연결합니다. 이름은 영어로, 예: seongsil-memo-app.
  4. 바뀐 파일을 확인하고 메시지(예: 첫 백업)를 적은 뒤 Commit → Push를 누릅니다.
  5. github.com에서 내 저장소에 파일이 올라왔는지 눈으로 확인합니다. 원하면 auto-sync를 켜서 자동으로 맞춰지게 할 수 있어요.

꼭 알아둘 것 3가지

1. API 키(Secrets)는 따라오지 않아요. 주식 API 키 같은 비밀값은 백업 파일에도 GitHub에도 안 들어갑니다. 메모장에 따로 적어 안전한 곳에 보관하세요.

2. API 키를 코드에 직접 쓰지 마세요. GitHub 저장소가 공개(public)면 누구나 보고 그 키로 요금을 쓸 수 있어요.

3. 데이터베이스는 따로예요. 앱에 저장된 회원·메모 데이터는 ZIP이나 GitHub로 옮겨지지 않습니다. 데이터가 중요한 앱은 따로 내보내야 해요.
