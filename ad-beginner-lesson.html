왕초보 · 수익화 기초

네이버 애드포스트 + 구글 애드센스
완전 기초 레슨

처음 들어도 이해할 수 있게, “광고 붙이고 클릭되면 돈이 조금 생기는 구조”를 설명합니다.

1. 이게 뭔가요? (한 줄)

애드포스트 = 네이버가 내 블로그에 광고를 붙여 주고, 누가 보면/클릭하면 내 몫 수익을 주는 서비스.

애드센스 = 구글이 내 웹사이트(예: GitHub 페이지)에 광고를 붙여 주고, 마찬가지로 수익을 나누는 서비스.

공통점: 내가 글을/사이트를 만들고 → 사람이 옴 → 광고가 보임/클릭됨 → 아주 작은 돈이 쌓임.

2. 수익은 어떻게 생기나요?

용어 3개만

  • 노출(Impression): 광고가 화면에 보임
  • 클릭(Click): 누가 광고를 누름
  • CPC: 클릭 1번에 광고주가 내는 돈 중 내 몫 (수십 원~수백 원 수준인 경우 많음)

대략: 방문자 수 × (그중 광고 클릭 비율) × 클릭당 금액 = 수익

왕초보 현실: 하루 방문 20명이면 수익은 0원~수백 원일 수도 있습니다. “복권”이 아니라 “작은 잔돈 모으기”에 가깝습니다.

애드포스트 돈 받는 법

  1. 블로그 승인(검수 통과)
  2. 글에 자동으로 광고 붙음
  3. 수익이 쌓임 (예: 5만 원 이상 등 조건)
  4. 등록한 본인 명의 계좌로 지급

애드센스 돈 받는 법

  1. 사이트 소유 확인 + 심사 통과
  2. 페이지에 광고 코드
  3. 수익 임계치(보통 일정 금액) 넘으면 송금
  4. 세금·주소 정보 필요

3. 수익 내는 사람들은 어떻게 하나요?

성공하는 분들은 보통 아래를 합니다.

  1. 검색되는 글을 꾸준히 씀 (예: “부천 피아노조율 비용”, “애드포스트 신청”)
  2. 하루 방문자를 늘림 (목표 감각: 애드포스트는 일 100명 전후가 유리하다는 이야기가 많음)
  3. 짧은 글 복붙보다 도움 되는 긴 글
  4. 한 주제(피아노/조율/지역)로 전문성
  5. 자기 광고 클릭 금지 (적발 시 정지)
유형하는 일수익 감각(대략)
초보 블로거글 30~100개, 방문 적음월 0~수만 원
꾸준한 블로거검색 유입 안정월 수~수십만 원 가능(케이스마다 다름)
대형/인플루언서방문 매우 많음월 백만 단위도 가능
사이트+애드센스정보 사이트 트래픽방문·국가·주제에 따라 천차만별

4. 애드포스트 vs 애드센스 (왕초보 비교)

네이버 애드포스트구글 애드센스
어디에?네이버 블로그 등내 웹사이트(GitHub 등)
누가 붙이나네이버 광고구글 광고
승인 난이도비교적 낮다는 평더 깐깐한 편
GitHub 사이트직접 수익 X (블로그만)O (사이트 심사)
내 경우블로그 등록·검수 요청 완료GitHub 소유확인·검토 요청 완료

정리: 블로그 돈 = 애드포스트, 내 홈페이지 돈 = 애드센스.

5. 지금 내 상황 (성실피아노 / pianopks)

  • 애드포스트: 가입 완료, 블로그 미디어 등록, 선호주제 음악, 검수 대기(약 5영업일)
  • 애드센스: 계정 생성, poianopks.github.io ads.txt·검토 요청, 대표 페이지에 스크립트 삽입
  • GitHub 사이트에는 애드포스트 광고가 안 붙음 → 블로그로 수익
검수/심사는 “접수 완료”이지 “이미 돈 벌림”이 아닙니다. 통과 메일을 기다려야 합니다.

6. 왕초보가 앞으로 할 일 (쉬운 순서)

  1. 블로그에 검색되는 글 주 2~3개 (조율·운반·지역명)
  2. 자기 광고 클릭 금지
  3. 애드포스트 검수 메일 확인
  4. 애드센스 승인되면 주소/세금 정보 입력
  5. 방문자 통계 가끔 보기 (하루 몇 명인지)

금지

  • 친구에게 “광고 눌러줘” 부탁
  • 도배·복사 글만 올리기
  • 가짜 클릭 프로그램

부록 · 한 문장 암기

“좋은 글 → 사람 옴 → 광고 보임 → 아주 조금 쌓임 → 계좌로 받음.”
