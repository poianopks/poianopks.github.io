💡
트랙 만드는 순서
1. + 버튼 → Software Instrument → Create
2. 트랙 이름 더블클릭 → "Keyboard" 입력
3. Y 키 → Library → Piano → E-Piano
4. 같은 방법으로 Electric Guitar, Bass Guitar, Drum set 추가
💡 트랙 순서: Keyboard → Electric Guitar → Bass Guitar → Drum set (악보 총보 순서와 일치)
🟩 피아노 롤 + Pitch Bend 실습

격자 클릭 = 노트 추가, 노트 클릭 = 삭제+재생. Pitch Bend 곡선도 직접 그려보세요!

🎹 Keyboard Quantize: 1/16 노트: 0개
