📌 레슨 1. 먼저 알아 둘 말

말쉬운 뜻
AsideAI가 들어 있는 인터넷 브라우저. 컴퓨터에 설치해서 써요.
텔레그램 봇텔레그램 안의 "자동 응답 친구". 봇에게 메시지를 보내면 내 컴퓨터의 Aside가 대신 일해 줘요.
BotFather텔레그램 봇을 만들어 주는 "봇 공장" 공식 계정이에요.
토큰(Token)봇의 비밀 열쇠예요. 이 열쇠가 있으면 누구나 봇을 조종할 수 있어요.
사생활 모드(Privacy Mode)봇이 모든 메시지를 볼지 정하는 스위치. Aside에 연결하려면 꺼야(Disable) 해요.
Pairing(짝 맺기)"이 텔레그램 계정만 내 봇을 써도 돼"라고 승인하는 단계예요.
Claude 세션Claude와 나누는 대화 한 개. 세션마다 할 수 있는 일과 허락이 따로따로예요.

📌 레슨 3. 임시 실패, 왜 실패했을까?

① 봇 하나를 컴퓨터 두 대가 같이 썼어요
텔레그램 봇은 전화번호 하나와 같아요. 두 컴퓨터가 같은 번호로 동시에 전화를 받으려 하면, 텔레그램은 한쪽만 연결하거나 둘을 번갈아 끊어 버려요.
② 사생활 모드를 엉뚱한 봇에 껐어요
BotFather에서 /setprivacy를 보낸 뒤 새 봇(@Aside_win10_bot)이 아니라 예전 봇(@Aside_rc_bot)을 골랐어요. 그래서 Aside가 계속 "Privacy Mode를 꺼야 연결된다"고 경고했어요.
③ 새 토큰을 예전 봇 칸에 넣었어요
새 봇은 새 항목으로 추가해야 하는데, 예전 봇(Aside_rc_bot) 설정 칸의 토큰만 바꿨어요. 경고 때문에 저장도 안 됐어요.
④ AI끼리 말을 전달하면 "허락"이 전달되지 않았어요
저(윈도우10 에고라이트 세션)는 화면 조작 기능이 없어서, 화면을 다룰 수 있는 다른 Claude 세션에게 일을 전달했어요. 그런데 텔레그램 봇 변경은 "계정 설정 변경"이라서, 그 세션의 안전장치가 "사용자 본인이 직접 말해야 한다"며 멈췄어요. 다른 AI가 대신 전한 "해도 돼"는 허락으로 인정되지 않아요. 그래서 시간이 걸렸어요.
⑤ 허락 창은 PC 화면에만 떠요
Claude가 새 프로그램(Aside)을 쓰려면 PC 화면의 Claude 앱에서 [이 세션 동안 허용]을 눌러야 해요. 스마트폰에는 그 창이 뜨지 않아서, 밖에 있는 동안에는 자동으로 거부됐어요.
⑥ (참고) 삼성 노트북의 "Insufficient credits" 오류는 잠깐 났다가 해결됐어요
08:27에 삼성 봇이 "Insufficient credits"(사용량 부족)라고 답했어요. 연결 문제가 아니라 Aside 사용량(크레딧) 때문에 생긴 일시적인 오류였어요. 09:27에는 삼성 봇도 정상으로 답했어요. 지금은 두 봇 모두 잘 작동해요.

📌 레슨 4. 완전 성공, 왜 성공했을까?

① 본인이 그 세션에 직접 "진행해"라고 말했어요
화면을 다룰 수 있는 Claude 세션에 사용자가 직접 허락하자 안전장치가 풀렸어요.
② AI끼리 의논하게 했어요 (Claude ↔ Aside)
Claude가 Aside 대화창에 상황을 영어로 설명하고 "답은 한국어로 해 줘"라고 부탁했어요. 영어로 물으면 AI가 기술 용어를 더 정확하게 알아듣는 경우가 많아요.
③ Aside의 "자동 방식"을 골랐어요
수동 방식(사람이 토큰을 복사해 붙여 넣기) 대신 "Ask Aside to set it up(Aside에 맡기기)"을 골랐어요. Aside가 로그인된 텔레그램 웹에서 BotFather와 직접 대화해서, 사생활 모드 끄기와 토큰 입력을 정확한 봇에 해 줬어요.
④ 봇 1개 = 컴퓨터 1대로 나눴어요
윈10에서는 예전 봇을 빼고 새 봇만 연결했어요. 삼성 노트북은 예전 봇을 그대로 써요.
⑤ 확인까지 했어요
새 봇에게 물어보니 PowerShell로 직접 확인해서 DESKTOP-0QU6PRB / Windows 10이라고 정확하게 답했어요. 봇이 진짜 그 컴퓨터에 연결됐다는 증거예요.

📌 레슨 5. 이렇게 하면 실패해요 ❌

  • ❌ 봇 하나를 컴퓨터 여러 대에 연결하기
  • ❌ /setprivacy 다음에 봇 이름을 확인하지 않고 아무 버튼이나 누르기
  • ❌ 새 봇 토큰을 예전 봇 칸에 덮어쓰기
  • ❌ AI에게 "다른 AI가 허락했으니 해"라고 시키기 (안전장치가 막아요)
  • ❌ 밖에서 스마트폰으로 처음 쓰는 프로그램을 허락하려고 하기 (허락 창은 PC에만 떠요)
  • ❌ 토큰을 채팅이나 메모에 그대로 붙여 넣기

📌 레슨 6. 이렇게 하면 성공해요 ✅

  • ✅ 봇 1개 = 컴퓨터 1대 (컴퓨터가 3대면 봇도 3개)
  • ✅ BotFather 답장에 내가 고른 봇 이름이 나오는지 꼭 확인하기
  • ✅ 새 봇은 Aside에서 Channels → Telegram "+"로 새 항목 추가하기
  • ✅ 어려우면 Aside 자동 방식(Ask Aside to set it up) 쓰기
  • ✅ 계정 설정을 바꾸는 일은 그 일을 하는 AI 세션에 내가 직접 허락하기
  • ✅ 밖에 나가기 전에 PC 앞에서 쓸 프로그램을 미리 모두 허용해 두기
  • ✅ AI끼리 의논시킬 때는 "영어로 묻고, 한국어로 답해 줘"

📌 레슨 7. 봇 2개 · 3개 만드는 절차 (따라 하기)

🅰️ 자동 방식 (추천, 가장 쉬움)

  1. 새 봇을 연결할 컴퓨터에서 Aside를 열어요.
  2. Aside 안에서 텔레그램 웹(web.telegram.org)에 로그인해 둬요.
  3. Aside 설정 → Channels → Telegram "+"를 눌러요.
  4. "Ask Aside to set it up"을 골라요.
  5. Aside가 묻는 질문에 답해요. 예: 봇 이름 Aside_노트북2_bot
  6. Aside가 BotFather에서 봇 만들기, 사생활 모드 끄기, 연결까지 해 줘요.
  7. Pairing 탭에 내 텔레그램 계정의 요청이 오면 내 계정이 맞는지 확인하고 Approve를 눌러요.
  8. 텔레그램에서 새 봇에게 "이 컴퓨터 이름이 뭐야?"라고 보내서 확인해요.

🅱️ 수동 방식 (직접 하기)

  1. 텔레그램에서 @BotFather를 찾아 /newbot을 보내요.
  2. 봇 표시 이름을 정해요. 예: 노트북2_Aside
  3. 봇 사용자 이름을 정해요. 꼭 bot으로 끝나야 해요. 예: Aside_note2_bot
  4. BotFather가 주는 토큰을 복사해요. 절대 남에게 보여 주지 마세요.
  5. /setprivacy를 보내고 방금 만든 봇을 골라요. 답장에 봇 이름이 맞는지 확인해요.
  6. Disable을 보내고 "Success! … DISABLED"가 나오는지 확인해요.
  7. 그 컴퓨터 Aside의 설정 → Channels → Telegram "+"에 토큰을 붙여 넣고 연결해요.
  8. Pairing에서 내 계정을 승인해요.
  9. 텔레그램에서 새 봇에게 인사해서 확인해요.
💡 컴퓨터가 3대면 위 절차를 3번째 컴퓨터에서 한 번 더 하면 돼요. 봇 이름에 컴퓨터 이름을 넣으면 헷갈리지 않아요. 예: Aside_home_bot, Aside_note_bot, Aside_office_bot

📌 레슨 8. 봇 여러 개 충돌 없이 쓰는 규칙

규칙이유
1. 봇 1개는 컴퓨터 1대에만 연결같은 봇을 두 곳에서 받으면 서로 싸워요.
2. 봇 이름에 컴퓨터 이름 넣기텔레그램 방 목록에서 어떤 컴퓨터인지 바로 알 수 있어요.
3. 컴퓨터를 바꾸면 예전 컴퓨터에서 봇 끄기Aside Channels에서 스위치를 끄거나 항목을 빼요.
4. 각 컴퓨터는 켜 두고 Aside도 실행해 두기컴퓨터나 Aside가 꺼져 있으면 봇이 대답하지 못해요.
5. 각 컴퓨터 Aside의 사용량(크레딧) 확인크레딧이 떨어지면 "Insufficient credits" 오류가 나요. 다른 구독(Copilot 등)을 연결하면 해결돼요.
6. 처음 연결하면 "컴퓨터 이름" 물어보기봇이 진짜 그 컴퓨터에 연결됐는지 확인하는 가장 쉬운 방법이에요.
예시: 컴퓨터 3대 텔레그램 방 "집_Aside" ─▶ @Aside_home_bot ─▶ 집 PC 텔레그램 방 "노트북_Aside" ─▶ @Aside_note_bot ─▶ 노트북 텔레그램 방 "사무실_Aside" ─▶ @Aside_office_bot ─▶ 사무실 PC

📌 레슨 9. 비밀 키(토큰) 안전 수칙 🔐

  • 토큰은 Aside 설정 칸에만 넣어요. 채팅, 메모, 블로그에 붙여 넣지 마세요.
  • 실수로 보여 줬다면 BotFather에서 /revoke → 그 봇을 골라 새 토큰을 받고, Aside에 새 토큰으로 바꿔 넣어요.
  • Pairing은 내 텔레그램 계정만 승인해요. 모르는 계정은 Approve하지 마세요.
