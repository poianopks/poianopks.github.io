Computer란 무엇인가?

Comet AI 안에 있는 가장 강력한 메뉴 기능입니다

💡 한 줄 정의

Computer는 Perplexity가 만든 AI 에이전트로, 단순히 질문에 답하는 것을 넘어서 실제 작업을 수행하는 도구입니다. 웹 검색, 코드 실행, 문서 작성, 브라우저 자동화, 400개 이상의 앱 연동, 메모리 기억, 예약 작업까지 — 모두 하나의 대화 안에서 처리합니다.

핵심 포인트
일반 AI 챗봇은 "답변"만 합니다. Computer는 답변 + 실행까지 합니다.
예를 들어 "경쟁사 가격 조사해서 엑셀로 정리해줘"라고 하면, 직접 웹을 검색하고, 데이터를 수집하고, 엑셀 파일을 만들어서 전달합니다.
🏢 만든 곳: Perplexity AI

2022년 설립된 샌프란시스코 기반 AI 회사입니다. "지식을 보편적으로 접근 가능하고 유용하게 만든다"는 미션을 가지고 있으며, AI 답변 엔진으로 시작해 검색, 에이전트, 브라우저, API까지 다양한 제품을 만들고 있습니다. Computer는 Perplexity의 제품 중 가장 진화된 에이전트 기능입니다.

왜 Computer를 사용하는가?

다른 AI와 근본적으로 다른 5가지 이유

🔗 하나의 세션에서 전부

검색, 코드, 문서, 연동 기능을 툴을 바꿔가며 할 필요 없이 한 대화에서 모두 처리합니다. 복사-붙여넣기 시대는 끝.

🧠 당신을 기억합니다

이름, 직업, 선호 스타일, 프로젝트 정보 등을 세션 간에 기억합니다. 매번 처음부터 설명할 필요가 없습니다.

🤖 멀티모델 지능

Claude, GPT, Gemini 등 여러 AI 모델을 작업에 따라 자동 선택하거나 직접 지정할 수 있습니다.

⚡ 병렬 처리 능력

100개 회사 동시 조사, 50개 사이트 동시 데이터 수집 등 대규모 작업을 서브에이전트가 병렬로 처리합니다.

📅 자동 예약 실행

"매일 아침 9시에 뉴스 요약해줘", "매주 월요일에 보고서 만들어줘" — 반복 작업을 예약하고 알림까지 받습니다.

🌐 400+ 앱 연동

Gmail, Slack, Notion, Google Calendar, GitHub 등 400개 이상의 외부 서비스와 직접 연결하여 읽기/쓰기가 가능합니다.

4

Computer 핵심 기능 10가지

이 기능들이 하나의 대화 안에서 조합되어 작동합니다

🔍 1. 리서치 엔진

웹, 학술, SNS, 이미지, 영상, 인물, 쇼핑 등 7가지 검색을 병렬로 수행합니다. 단순 검색이 아니라 페이지 전체를 읽고 분석합니다.

🌐 2. 브라우저 자동화

클라우드 브라우저를 실행하여 로그인 필요한 사이트, 폼 작성, 데이터 추출, 스크린샷 촬영 등을 자동으로 수행합니다. 수십 개 URL을 동시에 처리합니다.

💻 3. 코드 실행 (Linux 샌드박스)

격리된 Linux 환경에서 Python, Node.js, 셸 명령어를 실시간 실행합니다. 데이터 분석, 차트 생성, 파일 처리, 자동화 스크립트 등을 즉시 수행합니다.

📄 4. 전문 문서 생성

PDF, Word(DOCX), PowerPoint(PPTX), Excel(XLSX) 등 전문적인 문서를 직접 생성합니다. 차트, 서식, 페이지 번호, 목차 등 완성도 높은 결과물을 제공합니다.

🎨 5. 미디어 생성

AI 이미지, AI 영상, 텍스트 음성 변환(TTS), 오디오/비디오 자막 생성 등을 수행합니다. 모델을 선택하여 품질/비용을 조절할 수 있습니다.

🚀 6. 라이브 웹사이트 배포

HTML/CSS/JS 웹사이트를 만들고 공개 URL로 즉시 배포합니다. 수정 후 같은 URL로 재배포도 가능합니다. 포트폴리오, 랜딩페이지, 게임까지.

🔌 7. 400+ 외부 앱 연동

Gmail, Slack, Notion, Google Calendar, HubSpot, GitHub, Jira 등 400개 이상의 서비스와 연동합니다. 이메일 전송, 일정 생성, 문서 검색 등이 가능합니다.

🧩 8. 서브에이전트 (병렬 처리)

대규모 작업을 여러 AI 에이전트가 동시에 나누어 처리합니다. 100개 회사를 동시에 조사하거나 10개의 보고서를 동시에 작성합니다.

💾 9. 영구 메모리

사용자의 이름, 직업, 선호도, 프로젝트 정보를 세션 간에 기억합니다. "지난번 분석 이어서 해줘"가 가능합니다.

⏰ 10. 예약/스케줄링

반복 작업(매일, 매주), 지연 실행(내일 9시에 전송), 알림(새로운 정보 발견 시 푸시 알림) 기능을 제공합니다.

브라우저 제어로 작동하는가?

답변: 브라우저 제어는 Computer가 가진 여러 기능 중 하나입니다

결론부터 말하면
Computer는 브라우저 제어 "만으로" 작동하지 않습니다.
브라우저 자동화는 10가지 핵심 기능 중 하나일 뿐이며, 대부분의 작업은 프로그래밍 방식의 검색과 코드 실행으로 더 빠르게 처리합니다.
⚖️ 언제 브라우저를 사용하고, 언제 사용하지 않나?
상황 사용하는 방식
공개 웹페이지에서 정보 검색 브라우저 X 프로그래밍 검색 (더 빠름)
로그인이 필요한 사이트 접근 브라우저 O 클라우드 브라우저 실행
폼 작성, 버튼 클릭 등 UI 조작 브라우저 O 자동화 작업
데이터 분석, 차트 생성 브라우저 X Linux 샌드박스에서 코드 실행
문서(PDF, PPTX 등) 생성 브라우저 X 코드로 직접 생성
JavaScript로 렌더링되는 동적 콘텐츠 브라우저 O 풀 브라우저로 렌더링
50개 경쟁사 웹사이트 가격 수집 브라우저 O 병렬 브라우저 자동화
Gmail 이메일 전송 브라우저 X API 연동으로 직접 전송
왕초보 정리
Computer는 가장 효율적인 방법을 자동으로 선택합니다.
검색이 빠르면 검색을, 브라우저가 필요하면 브라우저를, 코드가 필요하면 코드를 실행합니다.
사용자는 "무엇을 원하는지"만 말하면 됩니다. "어떤 방법을 쓸지"는 Computer가 판단합니다.

다른 메뉴와 어떻게 다른가?

Perplexity 제품군 내에서 Computer의 위치

비교 항목 Perplexity 검색 Computer
주요 목적 질문에 대한 답변 답변 + 실제 작업 수행
작업 방식 검색 → 답변 제공 검색 + 코드실행 + 문서작성 + 연동 등 조합
결과물 텍스트 답변 (출처 인용) 파일(PDF, PPTX), 웹사이트, 데이터, 이메일 등
브라우저 자동화 제한적 클라우드 브라우저 + 로컬 브라우저 모두 지원
외부 앱 연동 제한적 400+ 앱 (Gmail, Slack, Notion 등)
코드 실행 제한적 Linux VM에서 Python, Node.js 등 실행
메모리 (기억) 기본적 영구 메모리 (사용자 정보 세션 간 유지)
예약 작업 불가 가능 (반복 작업, 지연 실행, 알림)
멀티모델 기본 모델 Claude, GPT, Gemini 등 선택 가능
대상 사용자 빠른 정보 검색이 필요한 모든 사람 복잡한 작업 수행이 필요한 전문가/파워유저
한마디로 정리
Perplexity 검색이 "똑똑한 검색엔진"이라면, Computer는 "일을 해주는 AI 비서"입니다. 질문에 답하는 것을 넘어, 결과물을 만들어내고 실제 서비스들과 연동하여 행동합니다.

Computer 사용 순서 따라하기

왕초보도 5분 안에 시작할 수 있는 단계별 안내

시작하기 전에
Computer를 사용하려면 Perplexity Pro 또는 Max 구독이 필요합니다. 무료 계정으로는 Computer 기능을 사용할 수 없습니다.
1
Perplexity 접속 및 로그인

웹 브라우저에서 perplexity.ai에 접속하거나 Comet 브라우저를 실행합니다. Google, Apple, 이메일 등으로 로그인합니다.

https://www.perplexity.ai
2
Computer 메뉴 선택하기

Perplexity 채팅 화면에서 입력창 아래 또는 상단에 있는 모드 선택에서 "Computer"를 선택합니다.
(일반 검색 모드와 다른 별도의 모드입니다)

3
원하는 작업을 자연어로 요청하기

코드나 명령어를 알 필요 없습니다. 평소 말하듯 요청하면 됩니다. 구체적일수록 좋은 결과가 나옵니다.

예시 1: "삼성전자 최근 3개월 주가 차트 만들어줘" 예시 2: "경쟁사 5곳의 가격 비교표를 엑셀로 만들어줘" 예시 3: "내 피아노 서비스 소개 웹사이트 만들어서 배포해줘" 예시 4: "매일 아침 9시에 네이버 인기 검색어 요약해서 알려줘"
4
Computer가 자동으로 작업 수행

요청을 분석하고 최적의 도구를 선택하여 작업을 수행합니다. 진행 과정이 실시간으로 화면에 표시됩니다. 필요한 경우 Computer가 추가 질문을 할 수도 있습니다.

5
결과물 확인 및 다운로드

완성된 파일(PDF, PPTX, XLSX 등)은 다운로드 버튼으로 받을 수 있습니다. 웹사이트는 공개 URL이 제공됩니다. 마음에 들지 않으면 "이 부분 수정해줘"라고 바로 요청할 수 있습니다.

6
(선택) 외부 앱 연결하기

Gmail, Slack, Google Calendar, Notion 등을 연결하면 더 강력한 워크플로우가 가능합니다. "내 Gmail 연결해줘"라고 요청하면 인증 링크가 제공되고, 클릭 한 번으로 연동됩니다.

초보자를 위한 팁
처음에는 간단한 요청부터 시작하세요.
  • "오늘 서울 날씨 알려줘" → 기본 검색 확인
  • "삼성전자 주가 차트 만들어줘" → 코드 실행 + 차트 확인
  • "간단한 자기소개 웹사이트 만들어줘" → 웹사이트 배포 확인
  • "이 PDF 내용 요약해줘" (파일 첨부) → 문서 처리 확인

궁금한 점을 빠르게 해결하세요

Computer 기능은 Perplexity Pro($20/월) 또는 Max 구독에 포함되어 있습니다. 무료 계정으로는 사용할 수 없습니다.
네, 한국어로 자연스럽게 요청하면 됩니다. Computer는 한국어를 포함한 다국어를 지원하며, 결과물(문서, 웹사이트 등)도 한국어로 생성합니다.
일반 AI 챗봇은 텍스트 답변에 초점을 맞추지만, Computer는 실제 파일 생성, 웹사이트 배포, 외부 서비스 연동, 예약 작업 등 "실행"에 초점을 맞춥니다. 또한 Claude, GPT, Gemini 등 여러 AI 모델을 작업에 맞게 자동 선택하는 멀티모델 방식을 사용합니다.
Computer의 브라우저는 격리된 클라우드 환경에서 실행되므로 사용자의 로컬 컴퓨터에 영향을 주지 않습니다. 또한 Comet 데스크톱 브라우저를 사용하면 기존 로그인 세션을 활용할 수도 있습니다.
메모리 기능은 사용자가 원하면 비활성화할 수 있습니다. 또한 일시적인 지시("이거 짧게 만들어줘")는 저장하지 않고, 직업, 선호도 같은 지속적인 정보만 저장합니다. 민감한 데이터는 저장하지 않도록 요청할 수 있습니다.
Computer가 배포하는 웹사이트는 공개 URL을 제공하며, 같은 프로젝트 경로로 재배포하면 동일한 URL이 유지됩니다. 장기 호스팅이 필요하다면 GitHub Pages나 별도 호스팅으로 옮기는 것을 권장합니다.
네, 전혀 문제 없습니다. Computer에게 자연어(일상 말)로 요청하면 됩니다. "차트 만들어줘", "보고서 써줘", "웹사이트 만들어줘" — 이렇게만 하면 Computer가 알아서 코드를 작성하고 실행합니다.
Computer의 일부 고급 기능(AI 이미지/영상 생성, 대규모 병렬 처리 등)은 크레딧을 소비합니다. Pro/Max 구독에 포함된 크레딧이 있으며, 잔액은 Perplexity 계정 설정에서 확인할 수 있습니다.
