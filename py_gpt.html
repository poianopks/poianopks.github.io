파이썬이 무엇인가요?

파이썬은 컴퓨터에게 무엇을 어떻게 하라고 글로 명령하는 언어입니다.

print("안녕하세요")

컴퓨터에게 “안녕하세요를 화면에 보여줘”라고 부탁한 것입니다.

DAY 01

print() — 화면에 보여주기

개념: print()는 글자, 숫자, 계산 결과를 화면에 보여주는 명령어입니다.
print("안녕하세요")
print(10)
print(7 * 8)
실행 결과안녕하세요 10 56

글자는 따옴표 안에 넣고, 숫자와 계산은 따옴표 밖에 씁니다. 글자와 계산을 함께 보여줄 때는 쉼표로 나눕니다.

print("7 곱하기 8은", 7 * 8, "입니다")
실행 결과7 곱하기 8은 56 입니다
오늘의 기억: print() = “화면에 보여줘!”
DAY 02

변수 — 이름표가 붙은 상자

개념: 변수는 글자나 숫자를 보관하는 이름표 상자입니다.
이름 = "박근성"
나이 = 67

print(이름)
print(나이)
실행 결과박근성 67

=는 “오른쪽 값을 왼쪽 상자에 넣어라”라는 뜻입니다. 변수 이름은 한글로 지을 수도 있습니다.

print(이름)    # 상자 안의 내용: 박근성
print("이름")  # 글자를 그대로: 이름
오늘의 기억: 변수 = 값을 보관하는 이름표 상자
DAY 03

숫자와 문자 — 내용물의 종류

개념: 파이썬에서는 자료의 종류를 타입(type) 또는 자료형이라고 합니다.
종류예뜻
정수67소수점 없는 숫자
실수170.5소수점 있는 숫자
문자열"67"따옴표 안의 글자
print(10 + 20)      # 숫자 계산
print("10" + "20")  # 글자 이어 붙이기
실행 결과30 1020
오늘의 기억: 67은 숫자, "67"은 글자입니다.
DAY 04

계산 — 더하기·빼기·곱하기·나누기

계산기호예결과
더하기+10 + 212
빼기-10 - 28
곱하기*10 * 220
일반 나누기/10 / 25.0
몫만 구하기//10 // 33
나머지%10 % 31
가격 = 5000
개수 = 3
합계 = 가격 * 개수

print("합계는", 합계, "원입니다")
실행 결과합계는 15000 원입니다
오늘의 기억: 일반 나누기는 / 하나, 몫만 구할 때는 // 두 개를 붙여 씁니다.
DAY 05

input() — 사람에게 물어보기

개념: input()은 사용자에게 질문하고 입력한 대답을 받습니다.
이름 = input("이름을 입력하세요: ")
print("안녕하세요", 이름, "님")
박근성을 입력했을 때안녕하세요 박근성 님

input()으로 받은 내용은 기본적으로 글자입니다. 계산하려면 int()로 정수로 바꿉니다.

나이 = int(input("나이를 입력하세요: "))
print("내년에는", 나이 + 1, "세입니다")
67을 입력했을 때내년에는 68 세입니다
오늘의 기억: input() = “물어보고 대답을 받아줘!”
DAY 06

if — 만약에

개념: 조건이 맞을 때와 맞지 않을 때, 컴퓨터가 서로 다른 일을 하도록 만드는 갈림길입니다.
나이 = 67

if 나이 >= 65:
    print("경로 우대 대상입니다")
else:
    print("아직 대상이 아닙니다")
실행 결과경로 우대 대상입니다
기호뜻
>크다
<작다
>=크거나 같다(이상)
<=작거나 같다(이하)
==서로 같다
!=서로 다르다

=는 값을 상자에 넣기, ==는 두 값이 같은지 비교하기입니다.

오늘의 기억: if = “만약 조건이 맞으면 이 일을 해줘!”
DAY 07

len() — 개수 세기

개념: len()은 글자의 길이나 리스트 안의 개수를 셉니다.
이름 = "박근성"
문장 = "피아노 조율"

print(len(이름))
print(len(문장))
실행 결과3 6

피 + 아 + 노 + 띄어쓰기 + 조 + 율 = 6입니다. 띄어쓰기도 한 글자로 셉니다.

오늘의 기억: len() = “몇 개인지 세어줘!”
DAY 08

리스트 — 여러 칸이 있는 큰 상자

개념: 리스트는 여러 값을 순서대로 한꺼번에 보관합니다. 대괄호 [ ]를 사용합니다.
악기들 = ["피아노", "바이올린", "기타"]

print(악기들)
print(악기들[0])
print(악기들[1])
실행 결과['피아노', '바이올린', '기타'] 피아노 바이올린

파이썬은 첫 번째를 1번이 아니라 0번부터 셉니다.

오늘의 기억: 리스트 = 여러 값을 순서대로 담는 큰 상자
DAY 09

for — 똑같은 일 반복하기

개념: for는 리스트의 값을 하나씩 꺼내며 같은 일을 반복합니다.
악기들 = ["피아노", "바이올린", "기타"]

for 악기 in 악기들:
    print(악기, "연주를 해봅시다")
실행 결과피아노 연주를 해봅시다 바이올린 연주를 해봅시다 기타 연주를 해봅시다

for 아래에서 반복할 명령 앞에는 반드시 들여쓰기를 합니다.

오늘의 기억: for = “하나씩 꺼내서 반복해!”
DAY 10

def — 나만의 함수 만들기

개념: 함수는 여러 명령을 하나로 묶어서 필요할 때 부르는 나만의 명령어입니다.
def 인사하기(이름):
    print("안녕하세요", 이름, "님")

인사하기("박근성")
실행 결과안녕하세요 박근성 님
def 곱하기(첫째수, 둘째수):
    답 = 첫째수 * 둘째수
    print("계산 결과는", 답, "입니다")

곱하기(7, 8)
실행 결과계산 결과는 56 입니다
오늘의 기억: def = “새로운 명령어를 만들겠습니다!”

이름 = input("이름을 입력하세요: ")
나이 = int(input("나이를 입력하세요: "))

if 나이 >= 65:

    print(이름, "님은 아직 대상이 아닙니다")
