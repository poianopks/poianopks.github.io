Aside AI 화면 메뉴 이름 총정리

상단 메뉴 타이틀 · 좌측 메뉴 타이틀을 HTML + SVG 도표로 보여 주고, 각 명칭의 개념목적이유와 실제 사용법을 왕초보 기준으로 정리한 공부 사이트입니다. 폰으로 볼 때는 오른쪽(또는 위) 모바일 버전 링크 버튼을 누르세요.

1. Aside 창 한눈에 보기 (SVG)

Windows에서 Aside를 켜면 대략 아래처럼 좌측 레일 + 상단 바 + 가운데 작업 영역으로 나뉩니다. 버전/언어에 따라 아이콘·문구가 조금 다를 수 있습니다.

왕초보 한 줄: 왼쪽은 “어디로 갈지”, 위는 “지금 창 도구”, 가운데는 “실제 웹”, 오른쪽(또는 옆 패널)은 “AI와 대화”입니다.

2. 상단 메뉴 타이틀 — 이름 · 개념 · 목적 · 이유

명칭(대표)개념목적왜 있나왕초보 사용법
뒤로 / 앞으로 방문 기록 한 칸 이동 이전·다음 페이지로 복귀 실수로 나갔을 때 복구 웹 보다가 이전 글 보고 싶을 때
새로고침 현재 페이지 다시 로드 최신 화면 받기 로딩 깨짐·데이터 갱신 장바구니/블로그가 이상하면 한 번
주소창 (Omnibox) URL 또는 검색어 입력 원하는 사이트로 이동 브라우저의 핵심 내비 naver.com, chrome://extensions
탭 (Tabs) 여러 페이지를 칸으로 유지 동시에 여러 일 닫지 않고 비교·복사 노션 탭 + 블로그 탭 같이
새 탭 빈 작업 공간 추가 새 검색/사이트 기존 탭 안 건드림 Ctrl+T 습관
Agent / AI 패널 / Chat Aside 에이전트와 대화 일을 시키고 결과 받기 Aside의 존재 이유 “노션에 정리해줘”처럼 한국어로
세션 (Session) 제목 이번 대화 작업 단위 일별로 대화 분리 섞이면 맥락이 망가짐 주제 바뀌면 새 세션 추천
모델 (Model) 어떤 AI 두뇌로 할지 속도/깊이 선택 쉬운 일·어려운 일 다름 빠른 일=fast, 긴 글=standard/deep
권한 (Permission) AI가 해도 되는 행동 범위 실수·위험 방지 발행/결제/삭제 보호 중요 작업 전 guard/확인 모드
확장 프로그램 브라우저 플러그인 번역·차단 등 보조 크롬 생태계 활용 chrome://extensions
계정 / 프로필 내 Aside·브라우저 신원 로그인·동기화 내 데이터 구분 구글 메일로 GitHub/노션 연동 시 확인
창 제어 (최소화 등) OS 창 버튼 Aside 창 크기 조절 Windows 표준 일반 앱과 동일

3. 좌측 메뉴 타이틀 — 이름 · 개념 · 목적 · 이유

좌측 명칭개념목적왜 쓰나사용법 팁
Home / 홈 대시보드 최근 세션·바로가기 시작점 필요 앱 키면 먼저 홈에서 상황 파악
New Chat / 새 채팅 새 세션 생성 새 주제의 일 시작 맥락 오염 방지 피아노 업무 vs 공부 레슨 분리
Chats / History 과거 세션 목록 이어서 하기 같은 일 반복 시 시간 절약 제목으로 검색·스크롤
Browser 내장 크롬형 브라우저 웹 작업의 무대 AI가 “손”으로 쓸 화면 로그인·확장·탭은 여기
Projects (프로젝트) 업무/고객/사이트 묶음 관련 세션·루틴 정리 여러 일을 섞지 않음 예: 성실피아노, 공부
Routines (루틴) 예약·반복·이벤트 작업 매일/매주 자동 실행 사람이 잊어도 실행 순위 체크, 아침 리포트 등
Memory (메모리) 장기 기억 요약 다음 세션에 사실 유지 매번 설명 안 해도 됨 가게명·전화·선호 저장
Skills (스킬) 특정 사이트/도구 전문 지침 노션·지메일·깃허브 잘 다루기 범용 AI보다 절차가 정확 필요 시 스킬 문서 자동 로드
Channels 슬랙·텔레그램 등 연결 메신저에서 일 시키기 Aside 창 밖에서도 지시 연결 후 채팅으로 요청
Artifacts / Files 결과 파일 보관함 HTML·PDF·다운로드 모음 채팅이 사라져도 파일 남김 레슨 사이트·엑셀 여기
Settings / 설정 환경 설정 모델·메모리·권한 기본값 내 방식에 맞추기 처음엔 기본값 유지 추천
Help / Docs 도움말 공식 설명 막힐 때 기준 문서 에러 나면 버전과 함께 확인

※ 실제 아이콘 라벨은 업데이트로 번역/이름이 바뀔 수 있습니다. 위 표는 역할 기준 개념 지도입니다.

4. Aside 핵심 용어 사전

Agent (에이전트)
시킴을 받아 브라우저·파일을 다루는 AI 일꾼.
Session (세션)
한 줄기의 대화+작업 기록 묶음.
Prompt (프롬프트)
내가 치는 지시문. 구체할수록 결과 좋음.
Tool (도구)
웹검색, 클릭, 노션, 깃허브 등 AI가 쓰는 기능.
Snapshot
페이지 구조를 글자 트리로 읽어 클릭 대상을 찾음.
REPL
브라우저를 코드처럼 조작하는 실행 환경.
Permission / Guard
발행·결제·삭제 전 사람 확인.
Routine
시간/이벤트에 맞춰 자동 재실행.
Project
관련 일을 폴더처럼 묶는 단위.
Memory
세션을 넘어 남는 사실·선호.
Skill
사이트별 베스트 프랙티스 설명서.
Artifact
사용자에게 보이는 산출 파일.
Channel
외부 메신저 연결 통로.
Compaction
긴 대화 압축해 맥락 유지.
Lasso
화면 일부 지정해 지시하는 기능(지원 시).
Daemon
백그라운드에서 Aside를 돌리는 엔진.

5. 왕초보 하루 사용 흐름 (SVG)

  1. Aside 실행 → 홈에서 상태 확인
  2. 새 채팅 → 오늘 주제 한 가지만
  3. 지시 → 목표 + 사이트 + 결과 형식 (예: “노션에 표로”)
  4. 브라우저 → 로그인 필요하면 본인이 한 번
  5. 확인 요청 → 발행/삭제/결제는 승인 후
  6. 산출물 → Artifacts / 노션 / 깃허브 Pages URL 저장

6. 10분 실습 과제

  1. 좌측에서 새 채팅을 만들고 제목을 왕초보-메뉴연습으로 생각하기
  2. 주소창에 chrome://extensions 입력해 상단·확장 개념 확인
  3. AI에게: “지금 열린 탭 제목 3개만 알려줘”
  4. 노션 또는 메모에 상단 3개 + 좌측 3개 이름 적어 보기
  5. 이 레슨 사이트 URL을 즐겨찾기
안전 수칙: 비밀번호를 채팅에 붙여 넣지 마세요. 결제·블로그 전체공개 발행은 확인 창을 읽고 승인하세요.

7. FAQ

Q. 크롬이랑 뭐가 다르나요?

브라우징은 비슷합니다. 차이는 옆에 AI 에이전트가 대신 클릭·정리·예약 작업을 할 수 있다는 점입니다.

Q. 메뉴 이름이 영문/한글이 섞여 보여요

정상입니다. 이 페이지 표의 역할로 이해하면 됩니다.

Q. 확장을 꼭 깔아야 하나요?

아니요. 번역 등 필요할 때만. Aside 핵심 기능과 겹치는 AI 확장은 최소로.

Q. 세션을 자꾸 새로 만들어야 하나요?

주제가 바뀌면 새로. 같은 일을 이으면 기존 세션.
