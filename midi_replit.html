Library 사용법
1. 트랙을 선택한 뒤 Y 키 누르기 → Library 패널 열림
2. 왼쪽 카테고리에서 Piano 클릭

💡 악기를 클릭하면 바로 소리가 바뀌어요. Musical Typing(⌘K)로 바로 테스트해 보세요!
🟩 피아노 롤 — 직접 노트 그리기

빈 격자를 클릭해서 초록색 노트를 추가하세요! 노트를 클릭하면 소리가 나요.

⏱ 1/16 Grid 노트: 0개 ● 초록=일반 / ● 노랑=선택
💡
Piano Roll 조작법
• 빈 곳 클릭: 노트 추가 + 소리
• 노트 클릭: 소리 재생 → 다시 클릭하면 삭제
• 실제 Logic Pro: Region 더블클릭 → Piano Roll 열림
• ⌘ + Option + 휠: 가로 줌인/줌아웃
💡 빠른 BPM(120)에서 1/16 그리드로 노트를 배치하면 신나는 리듬이 돼요!
⌨️ Musical Typing — 컴퓨터 키보드로 연주

⌘ + K로 열리는 Musical Typing 창입니다. 아래 키를 눌러 피아노처럼 연주해보세요!

Musical Typing — Track 1: Steinway Grand Piano
🟦 파란 키 = 피아노 음  ·  Z/X = 옥타브 내림/올림  ·  A = C4(도)
🎵 멜로디 자동 연주
🔄 Apple Loops 브라우저

5 키를 누르면 열리는 Apple Loops 브라우저입니다. 루프를 눌러서 미리 들어보세요!

Apple Loops
💡
Loop 사용법
• 파란색 (Audio Loop): 오디오 트랙에만 드롭 가능
• 초록색 (MIDI Loop): 빈 공간에 드롭 → 자동으로 악기 트랙 생성
• 루프를 Workspace에 드래그하면 자동으로 반복(Loop) 설정돼요
⚠️ Audio Loop를 MIDI 트랙에 드롭하면 안 돼요! 반드시 타입에 맞는 트랙에 드롭하세요.
⌨️ 필수 단축키 — 클릭하면 소리!
💡
Windows 키보드 사용자
Mac ⌘ = Windows의 Win(⊞) 키
Mac ⌥ Option = Alt 키
Logic Pro는 Mac 전용이지만, 외장 키보드로 쓸 때 알아두면 편해요!
